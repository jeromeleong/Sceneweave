## 核心端到端 fixture

零模組開始，建立兩集、同一角色與同一搭景。分別指定角色工作服／休閒服及搭景白天／雨夜，建立鏡頭，組裝固定 prompt，匯入兩份外部媒體作候選，明確採用一份並審核。更新角色作者稿，確認已採用快照不變。打包、關閉、搬移文件夾、重建索引，所有正式引用仍正確。

這個流程不能為了通過而安裝導演台、FFmpeg 或模型服務。輸入媒體使用測試 fixture，不需生成。

## 模組端到端 fixture

安裝官方 Stage 測試包，打開新格式工程、操作並產生真實預覽。保存引用、版本、hash、comment 及 Take。進行卸載，確認卡片、prompt、預覽、原始工程和輸出保留且操作能力消失。重裝支持同格式的包，恢复編輯；換成不支持的版本則只讀且不改 bytes。

## 文檔與性能

文檔檢查涵蓋連結目標、明確的 Design 標記、JSON 範例語法和決策一致性。未完成程式不得被 README 說成已提供。

性能先以固定硬件、瀏覽器／桌面版本、媒體 fixture 和規模建立基準，再將量測預算納入 CI。至少涵蓋大量文件索引、長鏡頭列表、上千邏輯節點及重型模組的按需載入。未量測前不得宣稱具體 FPS 或無上限支援。
