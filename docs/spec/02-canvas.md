# 02 · 無限畫布契約

狀態：V1 目標契約；未實作。依據：[00](00-decisions.md)、[03](03-vault-data.md)。

## 核心地位

畫布擁有自己的資料模型、命令、撤銷、搜尋、鍵盤操作與單獨測試。任何專業模組皆不得成為畫布建立或保存的前置依賴。`@xyflow/svelte` 只供互動渲染，不擁有正式資料或產品 Schema。

「無限」表示可平移縮放、按需讀取的邏輯工作平面，不表示數值可用 Infinity。所有座標與大小是有限數字，尺寸必須為正。世界座標、螢幕座標和裝置像素的轉換只發生在渲染邊界。

## 節點種類

| 種類 | 內容與責任 |
| --- | --- |
| note | 保存在此 Board 的短文字，適合便條 |
| document | 正式 Markdown／劇本等文件的引用 |
| media | 圖片、影片、音訊、模型文件的引用；模型僅通用卡片 |
| asset | 角色、搭景、道具、風格或自訂資產 |
| prompt | 某提示詞或 profile 的引用、版本和預覽 |
| entity | 集、場次、鏡頭、Take 等正式物件 |
| board | 另一張畫布的入口或快照預覽 |
| collection | 動態或靜態集合的入口 |
| editor | 專業模組工程的通用外殼 |
| group | 僅畫布組織，不是文件夾 |
| placeholder | 明確標示尚未提供的內容，不可當已完成資產 |
| link | 外部 URL；預設不抓遠端內容 |

貼紙是 note 的呈現樣式，不需要另一套權威資料。結構化表格是對實體或集合的視圖，不是把同一鏡頭資料複製成表格行。

## 身份與保存

每個節點有 `nodeId`，與 `objectId` 分開。同一個角色可以在同一張或多張畫布有多個節點。引用預設讀取該物件目前作者稿；需要連戲或交付穩定時指定精確 revision。

Board 以 `.swcanvas.json` 保存，至少包含 `schemaVersion`、`id`、`title`、`nodes`、`edges`。節點保存位置、尺寸、樣式、明確的 objectRef 或 board-local note。不得把資產 prompt、鏡頭狀態或文件正文再保存一份可修改副本。

預設選取、目前視角和目前分頁是裝置本地狀態；使用者明確「保存起始視角」才寫入共享 Board。多使用者不應互相搶鏡頭。

## 引用、連線與分組

`visual` 連線只表達排版意圖；`semantic` 連線引用正式關係 ID。正式關係可表示 references、derived_from、uses_revision 等，但不因拖一條普通箭頭就變成實際來源證據。

剪輯順序属于可選剪輯工程。來源紀錄區分軟件實際觀測的操作和外部提交者的聲稱；畫布位置與相鄰關係都不構成歷史。

分組保存明確成員 ID，不用幾何重疊推導。組不能直接或間接包含自身，一個節點在同一 Board 只能有一個直接群組父節點。移動組以統一座標轉換移動子節點；解散保留其世界座標。V1 允許一個成員的命名組，不照搬其他產品的至少兩個限制。

## 必要操作

建立／刪除／複製節點、加入引用、平移縮放、框選、多選、對齊、等距、網格排列、分組／解散、層級、鎖位置、搜尋定位、複製連結、跨畫布引用、局部資料讀取、按視窗範圍查詢。

Delete 預設只移除畫布實例；刪正式文件是另一個有依賴預覽與回收區的命令。複製卡片預設複製引用；「建立獨立資產副本」另行命名並分配新身份。

拖動期間可本地預覽；手勢結束用一次命令提交，不能每個 pointermove 寫一個歷史版本。Esc 回復預覽。若途中收到其他人的正式修改，按 revision 衝突处理，不把本地拖動覆蓋整張圖。

原子批次失敗回滾和成功後可撤銷是兩件事。可逆操作返回逆向 patch；撤銷前檢查受影響資料版本，不回滾別人後續操作。

## 下鑽與大型畫布

全劇→集→場→鏡頭是引用導航，不是把全劇塞在一張巨圖。Board 引用可形成關係，但遞歸嵌入必須偵測循環；遇循環顯示入口卡，不無限展開。

只掛載視口和必要緩衝區的重型節點，保留輕量空間索引。畫布上的導演台只顯示預覽，不每卡建立 WebGL 引擎。影片按需解碼，同時播放數有上限，離開視口後釋放昂貴資源。

agent 可按類型、範圍、標籤、objectId、bounds 分頁讀取，不必抓全圖或依靠截图辨認 ID。快照是可選驗收證據，不是讀取資料的必要入口。

## 模組缺失

所有 editor 卡片由核心提供基本外殼。未知或已卸載模組的內容仍保留引用、佔位大小、文件、版本、預覽、依賴與輸出。卡片不会被刪除、改成 note 或靜默修改其 payload。

專有畫布呈現器也必須提供核心 fallback；即使呈現器失效，仍可選取、移動與刪除該卡片實例。未知的新 schema 只允許保全／只讀，不猜測轉換。

## 無障礙與精確性

所有可見操作必須有可聚焦的按鈕或命令入口；節點可鍵盤選取、移動和打開；狀態不能只以顏色表達。提供列表視圖作為同一資料的替代檢視，不要求每個使用者都能操作空間畫布。

尺寸、比例與時長顯示區分實際媒體元資料和使用者預計值。佔位圖不是已取得素材，預覽快照不是完成輸出。驗收見 [11](11-acceptance.md)。
