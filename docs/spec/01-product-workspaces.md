# 01 · 產品與工作區

狀態：V1 目標契約；未實作。依據：[00](00-decisions.md)。

## 產品承諾

使用者打開一個普通文件夾，就能整理內容、建立畫布、固定人設和場景、安排鏡頭、收集候選、審核與打包。專業模組只是打開特定工程的額外工具。外部 agent 可以精確讀寫相同資料，不能取代人類的審核身份。

核心不以模型數量、生成速度或 token 為賣點。介面不設聊天欄、生成積分、模型渠道或隱藏推理任務。

## 工作範圍

| 範圍 | 預設內容 | 不代表什麼 |
| --- | --- | --- |
| Vault／Project | 全劇設定、各集、全域資產、畫布與交付 | 不代表雲端帳號或私有資料庫 |
| Episode | 劇本、場次、鏡頭與本集進度 | 不需要獨立複製全劇資產 |
| Scene | 一次敘事事件、出場人物、環境狀態與鏡頭 | 不是可重用搭景本身 |
| Shot | 製作要求、參考、候選、採用版本和審核 | 不是某一個 MP4 文件 |
| Board | 多個物件的視覺組合 | 不會改寫它們的原始歸屬 |
| Collection | 明確手選或條件篩選的引用集合 | 不是文件副本 |

季與 Sequence 是可選分類，不是建立鏡頭的必要前置。自由項目可以只有畫布、文件和資產；單片可直接有場次而沒有 Episode。核心不因沒有劇集層級而阻止使用。

## 場次與搭景

`Scene` 保存劇情的時間、情節、人物及連戲狀態；資產類型 `set` 保存可重用地點／搭景。兩個夜晚發生在同一咖啡店，可以是不同 Scene，並引用同一 SetRevision。

場景固定 prompt 指搭景的穩定外觀與空間結構。某集「雨夜、停電、窗邊多一把椅子」是場次狀態，不得直接改掉全劇咖啡店的固定描述。详見 [04](04-assets-prompts.md)。

## 共同資產與局部狀態

角色身份、骨相、固定疤痕與聲音設定可跨集使用；服裝、髮型、受傷、濕身、手持道具等用具名變體或局部狀態表示。哪些屬固定、哪些允許變化，由作者明確指定，不由軟件猜測。

鏡頭指定使用哪個人物與搭景版本。共享資產推出新版本後，舊鏡頭顯示更新提示，但不自动替換。某個版本只有一份正式內容，多張畫布只是引用。

## 主介面

中央始終是畫布工作面。左側是可收起的文件樹、工作範圍、資產與集合；右側是選取物件的屬性、prompt、引用、版本與審核。頂部提供路徑麵包屑、分頁、搜尋、儲存和權限狀態。任務與問題面板按需展開。

場次、鏡頭和文件可在畫布中直接編輯或開分頁。專業工程可開專業模組分頁／面板，關閉後回到原畫布位置。不是把使用者長期帶離畫布到另一個獨立產品。

角色檢視預設分為概覽、固定 prompt、變體、參考素材、使用情況、版本。搭景檢視提供相同骨架，另外顯示可變環境、空間標記與可選三維工程附件。

## 三種預設模板

劇集模板建立 Bible、Assets、Episodes、Boards、Collections、Reviews、Deliveries。單片模板不建多餘集數。自由模板只建立項目清單與第一張空白畫布。模板是資料配置，不是不同程式產品。

開空項目不得強迫匯入模型、安裝導演台或連接 agent。第一張卡片可以只是普通文字。

## 跨集組合

「所有雨夜鏡頭」「角色 A 的完整演出線」「預告片候選」使用集合或自由畫布。條件查詢只使用顯式欄位、全文與標籤，不假裝具有語義搜索。

集合的成員順序可以手動保存；它不是影片播放順序，除非使用者在可選剪輯器中明確建立時間線。

## 卸載後的使用者體驗

卸載導演台後，全劇畫布、角色資料、場景固定 prompt、分鏡圖、現有影片、審核和交付照常工作。相關工程卡片顯示「需要導演台模組」、檔案位置、格式、既有預覽和安裝入口。使用者仍可移动卡片、改顯示名稱、查看依賴或下載文件，不可假稱能進行三維編輯。

核心的完整驗收流程必须包含零模組項目，不能只展示安裝齊全的示例。
