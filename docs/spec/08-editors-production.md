# 08 · 可選編輯器與製作流程

狀態：V1 目標契約；未實作。依據：[01](01-product-workspaces.md)、[05](05-modules.md)。

## 零模組的完整工作流程

核心可以建立劇集／自由項目、寫劇本、建角色與搭景 prompt、整理參考、安排鏡頭、匯入已在外部完成的素材、比較候選、提交審核和打包交付。

零模組不承諾三維編輯或多軌影片渲染；使用者可在其他工具完成這些步驟。已輸出的普通媒體仍能在核心查看，因此核心產品價值不依賴某專業工具是否安裝。

## 導演台模組

官方可選 `director-stage` 負責人物／道具／搭景、變換、姿勢、動畫、走位、燈光、相機、切鏡及預演輸出。UI 全部以 Svelte 重做；可重用原本的 Three.js 算法，但資料和操作契約是新的 Stage 格式。

通用 EditorDocument 引用模組 payload。一份 Stage 工程可以服務一個或多個鏡頭；ShotBinding 使用 editorDocumentRef、stageSceneId、cameraId 和 timeRange。不能為每個鏡頭自動複製整份搭景。

新 Stage 公開單位統一為米、弧度、秒；帶角度的 UI 在邊界明確轉換。相機 FOV 欄位顯式命名單位，不沿用舊欄位猜測。所有時間與變換必須有限，負時長和無效引用拒絕。

資料操作、動畫取樣和渲染是不同能力。metadata 和可純資料驗證的操作不需開 UI；取景及輸出需要受控 renderer。模組不存在時不得把先前 screenshot 當成新渲染。

保存分鏡快照時登記真實工程版本、相機、時間、模組版本和輸出檔案。截圖是正式媒體，可在卸載後保留。幾何診斷不能證明構圖優美。

## 影片剪輯模組

`video-editor` 管理媒體軌、圖片、影片、配音、音樂、字幕、入出點、分割、速度、音量、基本轉場及輸出。它不是 Stage 動作時間線的另一個皮膚。

Edit 時間以 rational rate／timebase 表達，明確區分 source time、timeline time、幀率與可變幀率媒體的 presentation timestamp。不用浮點秒反覆四捨五入導致漂移。

首版以粗剪為範圍，不宣稱專業調色、複雜合成、完整音訊混音或所有格式的無損往返。外部工具工程可作 opaque file 保存；只有已安裝的對應能力才可編輯。

移除剪輯器保留專用工程外殼、字幕文件、依賴清單及已輸出的影片；核心不能在没有 renderer 時承諾重新輸出相同成片。

## 其他確定性模組

media-processing 可提供轉碼、裁切、抽幀、提取音軌、替換音軌及字幕燒錄。原生處理器以受控參數和文件範圍執行，不接受任意 shell。語音辨識、語義標籤和生成式修復不在非 AI 模組範圍。

基本字幕文本可以由核心作普通文件編輯；帶時間線預览與燒錄由相應模組提供。音訊可有逐句候選和聲音 profile，但核心不生成或克隆聲音。

## Take、審核與交付

Shot 是製作要求，Take 是一個候選。每個 Take 引用具體媒體及輸入 snapshot，可是外部生成、實拍、錄音、手繪或模組輸出。來源需區分 `observed` 與 `declared`：外部 agent 聲稱使用哪些模型／素材不能被平台偽裝成已驗證事實。

狀態分開保存：

| 維度 | 示例狀態 | 語義 |
| --- | --- | --- |
| 製作 | planned、in_progress、blocked、ready | 工作是否完成 |
| 審核 | not_submitted、pending、approved、changes_requested | 某個精確版本是否通過 |
| 採用 | selectedTakeId | 目前工作選擇，不必等於最終交付 |
| 交付 | draft、locked、superseded | 正式清單是否鎖定 |

新增 Take 不更改 selectedTakeId；提出選擇與批准需要相應權限。任務 succeeded 不会自动變成 approved。已鎖定交付引用不可變版本，不跟隨 working copy。

Review 綁定 objectId＋revisionId；影片留言另有來源時間點／範圍，圖片留言可有歸一化區域。媒體替換後舊評論留在舊版本，不錯誤搬到新內容的同一秒。

## 外部創作循環

外部 agent 讀鏡頭和固定 prompt → 在外部工具處理 → 將文件放在經授權的 staging／匯入位置 → 提交來源聲明 → 核心驗證並建立新 Take → 人類比較與審核 → 明確採用或交付。

外部服務憑證不存入角色 profile，不跟交付包外發。輸出不必在當次對話即刻完成，核心可追蹤外部來源的結果登記；但沒有真正結果不能提前標完成。

## 連戲

可顯式保存服裝、髮型、受傷、物品持有者、故事時間、視線、出入方向、相鄰鏡頭要求。軟件只檢查明確型別與引用，沒有 AI 不代表能自動推理劇情是否合理。

當共享角色、搭景或 prompt 更新，列出影響範圍和內容 diff。選擇升級是顯式資料變更；已批准或已交付內容不得被悄悄重算。

## 交付包

核心可收集正式文件、固定版本、普通媒體、審核、來源與依賴清單並打包。包內列出仍需模組才能編輯的工程；可選執行包不等於自动附送插件程式或第三方授權。

缺檔、未收集外部依賴、權利限制或被引用 revision 不存在时，交付驗證不通過。只有實際存在的文件及 hash 可以記為輸出；空佔位卡片不能成為完成證據。
