# 00 · 架構決策基線

狀態：Design baseline 1，2026-09-17；尚未實作。索引：[全部文檔](../README.md)。

## 目標

Sceneweave 是文件夾優先、無限畫布核心的製作工作台。沒有 AI 也能使用所有核心功能；沒有導演台也仍是一個完整產品。外部 agent 是操作者，不是核心內置服務。

## 強制決策

| ID | 決策 | 直接後果 |
| --- | --- | --- |
| D01 | 無限畫布是不可卸載核心 | 預設主工作面是畫布，不是工程選擇器或導演台 |
| D02 | 專業編輯器一律可選 | 導演台、剪輯器、合成器的安裝與生命週期獨立 |
| D03 | 核心可在零模組啟動 | 發行包、import graph、測試都不能依賴 Stage 或 Three.js |
| D04 | 真正文件夾優先 | Markdown、JSON、媒體為正式資料；資料庫只作索引 |
| D05 | 所有自有 UI 使用 Svelte 5 | 不保留舊 DOM 面板，不引入 React；算法仍可用 TypeScript |
| D06 | 不內建任何 AI | 不含模型供應商、推理、AI 聊天、語義標籤或偷偷調用外部模型 |
| D07 | 提示詞是核心資料 | 角色、搭景、風格、道具可保存固定 prompt，不依賴模組或模型 |
| D08 | 直接重構、無舊相容 | 不做 `.director` 遷移、旧 API 適配、混合格式 reader 或舊 UI 外殼 |
| D09 | 文件與畫布引用分離 | 刪卡片不刪檔；同一物件可出現於不同畫布 |
| D10 | UI 和 agent 共用命令核心 | 不允許另一條未驗證的 UI 直接寫入捷徑 |
| D11 | 發布版本不可原地改寫 | 新 prompt、資產或 Take 以新 revision 保存，交付使用精確版本 |
| D12 | 卸載程式不等於刪除資料 | 模組工程、參考、快照與輸出保留，核心仍可讀通用元資料 |
| D13 | 劇集結構與自由畫布共存 | 一部劇一 Vault 是預設，不是唯一合法組織方式 |
| D14 | 文檔與運行事實分開 | 寫出 API 不等於實作；驗收必須提供執行證據 |

## 核心與可選模組邊界

核心包含 Vault、無限畫布、文件／媒體基本檢視、資產與 prompt 編輯、基本劇集／場／鏡頭資料、集合、表格／分鏡條視圖、候選版本與審核、依賴打包、命令核心、權限、模組宿主和任務記錄。

核心不包含三維渲染器、三維搭景面板、多軌影片剪輯器、完整音訊工作站、FFmpeg 原生處理器、ComfyUI 執行器或任何生成服務。核心可播放普通媒體，但不因播放器存在而必裝完整編碼／剪輯工具鏈。

導演台可作為官方可選模組提供。核心安装器不強制安裝；開啟含導演台工程的 Vault 也不會自動下載它。可另外提供由使用者明確選擇的組合安裝方案，但核心單獨發行必須一直存在。

## prompt 與 AI 的明確界線

保存、版本化、替換明確變量、檢查引用、比較差異和輸出 prompt 包都是確定性功能。自動理解語意、改寫人設、選模型、生成附件、語音辨識或語意衝突判斷不屬於核心。

固定 prompt 的「固定」表示特定 revision 的文字與引用不可被下游靜默覆寫，不表示能強迫外部模型遵從，也不表示對任意自然語言衝突已有理解能力。

## 本次明確推翻的舊方案

不再建立舊工程匯入器或 `LegacyStage*` 常駐相容層。不先用 Svelte 包住旧面板交付。導演台不再是必帶引擎，首頁也不為導演台服務。原有 `.canvas` 相容與伴隨元資料方案不作 V1 負擔：采用公開但自有的 `swcanvas` v1 格式，一檔保存畫布專屬資料。

不做舊相容不代表可以刪除使用者舊文件。新應用不主動讀取、改寫或清除舊產品資料；不支援的工程明確顯示 unsupported。

## 演進規則

本基線約束新的 Sceneweave v1。格式擁有明確版本並拒絕未知 major，不承諾自動轉換；普通媒體匯入不屬於舊工程相容。日後變更需更新此決策、相關格式、範例和驗收，不只改一個實作分支。

初始技術選定 Svelte 5、TypeScript、Vite、`@xyflow/svelte` 和 Electron／Node 本地宿主。版本號在實作提交中鎖定；這不意味核心依賴某個 Three.js 版本。外部技術依據見 [13](13-sources-status.md)。
