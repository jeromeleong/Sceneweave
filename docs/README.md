## 文檔語義

「必須／不得」是目標產品的強制要求。「首版」指第一個可發布的 Sceneweave 核心，不是現有 DirectorDesk 程式。「後續」只表示延後的可選能力，不構成現在承諾已完成。

示例中的 ID、路徑、版本、SHA 示意值是虛構資料。agent 在實際操作時只能使用服務返回的真實身份與版本。

不得把一段 Markdown 的存在當作 Schema 已在程式執行。正式 JSON Schema、OpenAPI、MCP 映射與測試實作在開發階段產生，必須符合本套契約。

## 完整性

本套文件覆蓋產品邊界、交互、資料、prompt、模組、API、安全、交付和驗收。個別畫面像素、依賴精確版本及硬件性能基準須在實作時以證據固定；它們不得改變已定下的核心或引入舊格式相容。

文檔互有矛盾時，先停止相關寫入、修訂決策與關聯範例，不以靜默猜測建立另一套行為。變更記錄寫進 00，並同步更新 11 的驗收。
